# Tideloop

The public home of [Tideloop](https://jafforgehq.github.io/tideloop-app/), a week planner for macOS.

This repo holds the website and the signed, notarized releases. The app's source is at [`jafforgehq/Tideloop`](https://github.com/jafforgehq/Tideloop), under the MIT licence. Installed copies of Tideloop update themselves from the releases here.
